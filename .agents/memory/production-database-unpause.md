---
name: Production database unpause
description: Replit Support's confirmed recovery path for this project's billing-paused production database.
---

For this project, Replit Support confirmed production data is preserved during a billing pause. Even after top-ups succeed and the balance is restored, production may remain frozen until it is manually unpaused from the Database pane.

**Why:** The user supplied Support's steps and corrected the agent for repeating diagnosis instead of following them.

**How to apply:** If production still reports frozen after balance restoration, direct the user to Database → Production database → Unpause. Do not reset the database or change billing/configuration.
