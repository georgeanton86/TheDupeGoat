---
name: Scarcity messaging
description: How to present limited fragrance releases without misleading availability claims.
---

Show actual remaining inventory when promoting a limited run. Sizes that have no purchasable offer should be visibly unavailable, not described as sold out unless inventory for that size really existed and was exhausted. Avoid implied demand metrics based on arbitrary starting quantities.

**Why:** The user wants the collection to feel limited, but a fabricated sold count or false sold-out claim would mislead buyers; the real release size and remaining stock provide legitimate urgency.

**How to apply:** When editing product cards, collection banners, size options, or sale counters, derive availability from the current product data and label unavailable offers distinctly from sold-out stock.
